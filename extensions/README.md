# Extensions

Drop extension files (`my_extension.py`) or packages (`my_extension/__init__.py`)
here. They load automatically on start and hot-reload when you save them.

* Install ready-made ones with `/marketplace` (ZSync Marketplace).
* `example.py` shows the V2 API - cards, views, storage and hooks.
* V1 extensions keep working: `bot.register_hook`, `bot.db`, `bot.config.get`,
  `from atomic_file_system import global_file_handler`, `get_cog("Task Scheduler")` …

See `docs/EXTENSIONS.md` for the full guide.
