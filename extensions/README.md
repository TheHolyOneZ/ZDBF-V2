# Extensions

Put extension files (`my_extension.py`) or packages (`my_extension/__init__.py`) here. They load
on start and reload when you save them.

- Install ready-made ones with `/marketplace` (ZSync Marketplace).
- `example.py` shows the V2 API: cards, an interactive view, storage and a hook.
- V1 extensions keep working.

Guide: [docs/dev/extensions.md](../docs/dev/extensions.md). Adding a page to the web dashboard:
[docs/dev/dashboard-panels.md](../docs/dev/dashboard-panels.md).
